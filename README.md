# Многопоточная обработка данных на Java

Простая демонстрация работы с потоками (`Thread`) и синхронизации (`synchronized`) в Java. Два независимых потока безопасно обращаются к общему ресурсу для вывода данных в консоль.

## 🛠️ Технологии
* **Java 11+**
* **Многопоточность (Multithreading)**

## 🏗️ Архитектура проекта

Проект состоит из четырех основных классов в пакете `app`:

*   **`Main`** — точка входа. Создает общий репозиторий, обработчик и запускает два потока.
*   **`DataRepository`** — источник данных. Содержит массив строк со списком фруктов.
*   **`DataHandler`** — обработчик данных. Форматирует список. Метод вывода защищен блоком `synchronized (this)`, что предотвращает перемешивание вывода от разных потоков.
*   **`MyThread`** — кастомный класс потока. Наследуется от `Thread` и вызывает метод обработки данных.

## 🚀 Запуск проекта

1. Скомпилируйте исходный код:
   ```bash
   javac app/*.java
   ```
2. Запустите приложение:
   ```bash
   java app.Main
   ```

## 📋 Пример вывода в консоли

Благодаря синхронизации каждый поток выводит свою строку целиком, без разрывов:

```text
Thread 1: (1) orange (2) apple (3) plum (4) mango
Thread 2: (1) orange (2) apple (3) plum (4) mango
```
*(Порядок появления Thread 1 и Thread 2 может меняться при каждом запуске)*
